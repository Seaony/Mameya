# 404 页面的插画：迷路的小毛豆

这张图会放在网页 404 页面大字「4 0 4」中间，替代那个「0」。左右两边是很大的深色无衬线数字「4」（Geist 字体，粗细 600），所以插画整体要是一个竖着的、略扁的椭圆轮廓，高宽比约 1.25:1，和数字 0 的外形差不多。

- 主体：一颗拟人化的毛豆（青豆）小角色，站着或立着，表情有点迷茫，眼睛是两个小黑点，眉毛微微皱着，头顶有一个小小的问号或者一片小嫩芽。可以一只手举着一个很小的放大镜在找东西。可爱但克制，不要夸张。
- 风格：和一组 Mac App 图标同系列：柔和的软 3D / 黏土感，圆润，轻微的体积光影，表面干净光滑，没有粗描边。整体简洁，细节少。
- 配色：低饱和度的浅绿色。主体约 #8FB08A，暗部约 #5E7F59，亮部约 #D6E5D1，眼睛和眉毛用很深的墨绿 #1A1D19，放大镜用浅灰绿。不要出现鲜艳的绿色，不要黄色和橙色。
- 背景：完全透明（PNG 透明背景），角色下方不要地面、不要阴影投在背景上，不要白边。
- 构图：竖构图，角色居中，占画面高度约 85%，四周留少量空白。
- 画面里不要任何文字和数字（问号符号可以有）。
- 尺寸：1024×1280（竖版 4:5）。
